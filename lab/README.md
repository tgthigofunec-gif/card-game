# Memory Cards — Dev Lab

Jogo da memória responsivo feito apenas com HTML, CSS e JavaScript puro.

## Como executar
Abra `index.html` no navegador. Não precisa instalar dependências nem iniciar servidor.

## Estrutura
- `index.html` — estrutura da página
- `css/style.css` — visual e responsividade
- `js/script.js` — embaralhamento, pares, movimentos e cronômetro
- `assets/img/` — 9 SVGs quadrados de 512 × 512 px com fundo transparente

O jogo usa 8 ícones em pares (16 cartas) e um ponto de interrogação como verso das cartas.
